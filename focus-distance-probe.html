Focus Distance Probe

Reads camera lens focus state via the Image Capture API, and now scores actual image sharpness so "did it refocus" is a measured number, not something you have to eyeball. Logs locally to this phone only — nothing leaves the device except the CSV you export.

Manual Focus Drive

Tap a preset while pointed at a nearby object. Each tap drives the lens, waits ~0.6s to settle, then measures sharpness automatically — the result line below tells you objectively whether it refocused, no eyeballing needed.

Walk-Back Test Log

Tap Start Logging, then walk backward from the object with your tape measure. This forces continuous (auto) focus for the whole run and locks the manual controls above — a stray preset tap mid-walk would otherwise pin focusDistance and silently stop it tracking anything real. focusDistance and sharpness both log automatically 5x/sec. Whenever you read a distance off the tape, type it below and tap Mark to tie that tape reading to the live focusDistance/sharpness at that instant.
